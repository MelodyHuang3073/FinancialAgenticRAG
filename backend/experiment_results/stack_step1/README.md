# 疊加第 1 步:+ C1 語料庫(單檔 300 題)

疊加實驗的第 1 步(2026-11-08 修訂版規劃,見上一層的 [EXPERIMENT_PLAN.md](../EXPERIMENT_PLAN.md)),評分規則在其第 9 節。這一份是在目前的獨立測試集與訓練集重跑的版本:訓練集用 2026-11-20 的執行,獨立測試集用 2026-11-22 的執行。

## 這一步的設定

只加系統語料庫(C1),沒有加任何完整系統沒有的東西。

| 項目 | 內容 |
|---|---|
| 日期 | 2026-11-20 |
| 程式 | `backend/stack_runner/run_step.py --step 1`(本分支,「疊加實驗第 1 步程式」的 commit),4 個程序同時跑 |
| 模型 | gpt-5-mini;一次呼叫只有一則使用者訊息,不設任何其他參數 |
| 資料 | 系統解析好的語料庫(表格逐列重建、MinerU 修復段落,每個 chunk 帶結構化欄位),取代純文字切塊 |
| 檢索 | 步驟 0 的 `rank_bm25`,只用問題原文,取 16 筆;索引文字**只有 `content`**(和系統一樣) |
| 證據行 | 系統格式 `- [公司 / 表格名稱] 整頁內容`,每筆最多 4000 字或表格 30 列,同一頁被命中幾次就顯示幾次;沒有額外的標籤行 |
| 提示詞 | 步驟 0 的格式:`Context:`、證據行、空一行、`Question:`、問題;沒有系統訊息 |
| 跑法 | 訓練集 150 題與獨立測試集 150 題分兩階段、各 4 個程序依序執行,用量與耗時分開記錄(時間窗在 `run_windows.json`);先離線檢查提示詞 |
| 檢查 | 300 題齊全,0 次錯誤 |
| 評分 | 依規劃第 9 節逐題讀完 300 題答案,對標準答案評分,非 C 的標籤記依據(決策表列號或第 9.4 節規則),通過 `grading_check.py`,並與第 0 步、比較基準跨組比對 |
