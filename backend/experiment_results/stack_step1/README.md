# 疊加第 1 步:+ C1 語料庫(單檔 300 題)

疊加實驗的第 1 步(2026-11-08 修訂版規劃,見上一層的 [EXPERIMENT_PLAN.md](../EXPERIMENT_PLAN.md)),評分規則在其第 9 節。舊版第 1 到 4 步含額外的標籤行,已作廢刪除。

## 這一步的設定

只加系統語料庫(C1),沒有加任何完整系統沒有的東西。

| 項目 | 內容 |
|---|---|
| 日期 | 2026-11-08 |
| 程式 | `backend/stack_runner/run_step.py --step 1`(本分支,「疊加實驗第 1 步程式」的 commit),4 個程序同時跑(兩個題組各切 2 份),先冒煙測試 2 題 |
| 模型 | gpt-5-mini;一次呼叫只有一則使用者訊息,不設任何其他參數 |
| 資料 | 系統解析好的語料庫(表格逐列重建、MinerU 修復段落,每個 chunk 帶結構化欄位),取代純文字切塊 |
| 檢索 | 步驟 0 的 `rank_bm25`,只用問題原文,取 16 筆;索引文字**只有 `content`**(和系統一樣);兩份只有 13、14 筆的 8-K 取全部 |
| 證據行 | 系統格式 `- [公司 / 表格名稱] 整頁內容`,每筆最多 4000 字或表格 30 列,同一頁被命中幾次就顯示幾次;**沒有額外的標籤行** |
| 提示詞 | 步驟 0 的格式:`Context:`、證據行(單一換行)、空一行、`Question:`、問題;沒有系統訊息 |
| 檢查 | 300 題齊全,0 次錯誤,沒有空答案,合併檢查通過;離線驗證 300 題提示詞(沒有標籤行、一則使用者訊息) |
| 評分 | 依規劃第 9 節逐題讀完 300 題答案,對標準答案評分,非 C 的標籤記依據(決策表列號),通過 `grading_check.py`,與第 0 步、基準跨組比對 |

## 跨組比對(規劃 9.6)

- 與第 0 步:標籤相同 221 題。
- 與基準:標籤相同 211 題;基準非 C、這一步 C 的有 5 題(訓練集 121,獨立測試集 12、33、50、89)。
- 這一步非 C、第 0 步與基準都是 C 的 17 題(訓練集 27、40、47、51、60、89、101、114、138,獨立測試集 1、4、34、61、68、70、75、140),逐題對照後都是這一步的答案本身不同(找不到、用錯數字、換了結論),沒有標準不一致。
- 判斷依據的幾個決定(請注意):
  - 訓練集 55(Best Buy 門市數):結論「減少」對,但數字是 930 → 907,標準答案是 982 → 969,判 P(第 6 列);初版漏標成 C,2026-11-08 補正(第 2 步同一題的答案相同,判 P)。
  - 訓練集 110(MGM 短期投資):答「債務證券」,標準答案是公司債(約 82%),層級不對,判 W(第 6 列);初版漏標成 C,2026-11-08 補正。
  - 訓練集 3(3M 資本密集度):答「是,中度資本密集」,標準答案是「否」,判 W(第 14 列)。
  - 訓練集 51(Best Buy 毛利率是否穩定):答「不能假設穩定」,標準答案是「穩定」,判 W(第 14 列)。
  - 訓練集 85(General Mills 保留比率):答 54.5%,標準答案 0.54,輸入用含非控制權益的淨利,判 S(第 4 列)。
  - 訓練集 108(MGM 利息保障倍數):算出 −3.25,標準答案是「EBIT 為負,倍數為零」,判 P(第 6 列)。
  - 訓練集 119(PayPal 營運資金):不給正或負的結論,判 W(第 14 列)。
  - 訓練集 121(PepsiCo 地區):列出 North America、Latin America、Europe、AMESA、APAC,涵蓋標準答案的所有區域,判 C。
  - 獨立測試集 70(Pfizer 重組費用):同時給 $1,550M / $2,419M(標準答案,合計行)與 $1,092M / $1,987M(只有重組的行)兩個口徑、兩者並列,依第 20 列判 P;2026-11-11 與其他組統一(原判 C)。
  - 訓練集 134(Pfizer Upjohn):答約 $70M(700 × 10%),標準答案 77.78(700 ÷ 0.9 − 700),判 P(第 6 列)。
  - 訓練集 40(AmEx 營運地區):答美國,以及英國、歐盟、澳洲、日本、加拿大、墨西哥,標準答案是美國、EMEA、APAC、LACC,沒有寫出標準答案的其餘區域,依 9.4 節列舉題判 P(第 19 列);2026-11-11 與列 1、列 3 統一(原判 C)。
  - 訓練集 49(Best Buy 三年平均淨利率):用持續營運淨利並估算各年營收,算出 2.7%,標準答案 2.8%,判 P(第 6 列),與列 3 同題同口徑一致;2026-11-11 統一(原判 S)。
  - 訓練集 89(J&J 調整後 EPS 是否加速):答「Yes,但只是小幅」,標準答案是 No(3.6% 降到 3.5%),結論相反,判 W(第 14 列);2026-11-11 統一(原判 P)。

## 用量

300 題:合計 4,347,392 token(輸入 4,117,530、輸出 229,862;冒煙測試另外約 3 萬不計入)。每題耗時中位 8.7 秒;平均 29.3 秒被訓練集 111、114 兩題拉高(各約 2,500 秒,原因不明,答案內容正常),扣掉這兩題與訓練集 83(106 秒)後平均 12.1 秒。
