# 疊加第 1 步:+ C1 語料庫(單檔 300 題)

疊加實驗的第 1 步(2026-11-08 修訂版規劃,見上一層的 [EXPERIMENT_PLAN.md](../EXPERIMENT_PLAN.md)),評分規則在其第 9 節。這一份是 2026-11-20 在目前的獨立測試集與訓練集重跑的版本。

## 這一步的設定

只加系統語料庫(C1),沒有加任何完整系統沒有的東西。

| 項目 | 內容 |
|---|---|
| 日期 | 2026-11-20 |
| 程式 | `backend/stack_runner/run_step.py --step 1`(本分支,「疊加實驗第 1 步程式」的 commit),4 個程序同時跑 |
| 模型 | gpt-5-mini;一次呼叫只有一則使用者訊息,不設任何其他參數 |
| 資料 | 系統解析好的語料庫(表格逐列重建、MinerU 修復段落,每個 chunk 帶結構化欄位),取代純文字切塊 |
| 檢索 | 步驟 0 的 `rank_bm25`,只用問題原文,取 16 筆;索引文字**只有 `content`**(和系統一樣) |
| 證據行 | 系統格式 `- [公司 / 表格名稱] 整頁內容`,每筆最多 4000 字或表格 30 列,同一頁被命中幾次就顯示幾次;沒有額外的標籤行 |
| 提示詞 | 步驟 0 的格式:`Context:`、證據行、空一行、`Question:`、問題;沒有系統訊息 |
| 跑法 | 訓練集 150 題與獨立測試集 150 題分兩階段、各 4 個程序依序執行,用量與耗時分開記錄(時間窗在 `run_windows.json`);先離線檢查提示詞 |
| 檢查 | 300 題齊全,0 次錯誤 |
| 評分 | 依規劃第 9 節逐題讀完 300 題答案,對標準答案評分,非 C 的標籤記依據(決策表列號或第 9.4 節規則),通過 `grading_check.py`,並與第 0 步、比較基準跨組比對 |

## 跨組比對(規劃 9.6)

- 與第 0 步(同一次重跑):標籤相同 237 題。
- 與比較基準:標籤相同 179 題;比較基準非 C、這一步 C 的有 8 題(訓練集 109、121、141,獨立測試集 45、92、115、117、134),都是這一步的答案本身把標準答案要的內容寫出來了。
- 這一步非 C、第 0 步與比較基準都是 C 的 9 題(訓練集 27、47、51、60、114,獨立測試集 22、68、121、136),逐題對照後都是這一步的答案本身不同(找不到、用錯數字、換了結論),沒有標準不一致。
- 判斷依據的幾個決定:
  - 訓練集 3(3M 資本密集度)答「是,中度」、訓練集 63(Boeing 毛利率)答「否」、訓練集 136(Pfizer 是否分拆)答「否」:標準答案相反,判 W(第 14 列)。
  - 訓練集 40(AmEx 營運地區):答美國與英國、歐盟、澳洲、日本、加拿大、墨西哥,沒有標準答案的 EMEA、APAC、LACC 字樣,依列舉題判 P(第 19 列)。
  - 訓練集 121(PepsiCo 營運地區):北美、拉丁美洲、歐洲、AMESA(寫出 Africa、Middle East、South Asia)、APAC(寫出 Australia、New Zealand、China),十個地區都有,判 C。
  - 訓練集 85(General Mills 保留比率)答 54.52%,標準答案 0.54,輸入用含非控制權益的淨利,判 S(第 4 列);訓練集 49(Best Buy 三年平均淨利率)答 2.7%,標準答案 2.8%,輸入為估算值,判 S(第 4 列)。
  - 訓練集 108(MGM 利息保障倍數)算出 −3.25,標準答案是「EBIT 為負,倍數為零」,判 P(第 6 列);訓練集 134(Pfizer Upjohn)答約 $70M,標準答案 77.78,判 W(第 6 列)。
  - 訓練集 46(AWW)與 67(Boeing)沿用第 22 列(答案是可接受的解答,判 C)。
  - 獨立測試集 60(Costco 毛利率是否穩定)答 Yes,但毛利率以淨銷售額為分母(11.1% 等),標準答案用含會員費的總營收(12.8%、12.6%),判 P(第 9.4-4)。
  - 獨立測試集 77(JPM 是否高成長)與 147(MGM 資本密集):答案只有定性結論加其他比率,沒有標準答案要的數字,判 P(第 15 列);獨立測試集 79(JPM 員工數)答約 320,000,是財報(CEO 信)自己印的較粗略數字,判 C(第 7 列);獨立測試集 58(Costco 三年平均淨利率)答 2.9%,標準答案 2.8%,輸入與算法都對,判 S(第 1 列)。這四題在 2026-11-21 做第 2 步跨組比對時統一判法,原判 C、C、W、P。
  - 獨立測試集 146、148(Walmart)差最後一位,判 S(第 1 列);獨立測試集 57(Costco 存貨週轉率)算出 13.06,標準答案 13.05,判 S(第 1 列)。
