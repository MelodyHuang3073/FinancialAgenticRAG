這一份是 2026-11-19 在新獨立題組上重跑的版本;之前(舊獨立題組)的結果已刪除。

## 結果(C / S / P / W)

| | 題數 | C | S | P | W | 答對率 |
|---|---|---|---|---|---|---|
| 全部 | 300 | **278** | 2 | 11 | 9 | **92.7%** |
| 訓練集 | 150 | 145 | 0 | 2 | 3 | 96.7% |
| 獨立題組(新) | 150 | 133 | 2 | 9 | 6 | 88.7% |

依題型:算指標題 100 題 93 C(S 2、P 1、W 4);領域題 100 題 91 C(P 7、W 2);說明題 100 題 94 C(P 3、W 3)。
各考法(A 到 F)的細分可由 `answers.json` 的 `form` 欄位(只有獨立題組有)統計。

非 C 的題與判分依據都在 `labels.json` 與 `answers.json` 的 `note`。

評分規則 2026-11-19 修改(老師確認):兩個口徑都明確寫出、其中一個符合標準答案,改判 C(決策表第 20 列,見規劃文件第 9 節與變更紀錄);本組依新規則判分,訓練集 89 題因此是 C。

訓練集 86 題(J&J 是否高成長)原判 P,複核時發現疊加第 4 步對同樣寫法(以獲利下降為依據、沒有營收成長 1.3%)的答案判 C,依跨組一致改判 C。訓練集現在非 C 的 5 題是 109、135、141(W)與 119、121(P),其中 119、121、135 與上一次基準相同。

### 標準答案更正的兩題(2026-11-19)
新獨立題組是自己出的題,這兩題的標準答案有誤,查財報後更正,更正後本組重判:
- 獨立題組 88 Lockheed Martin 自由現金流:原標準答案 $7,615M;財報現金流量表的資本支出是 (1,649),公司定義的自由現金流 = 營業現金流 8,557 減資本支出,為 **$6,908M**。更正後答案(6,908)正確,由 W 改判 C。
- 獨立題組 97 MGM 是否資本密集:原標準答案的營收 $9,810M 在財報找不到;FY2025 淨營收是 $17,538M。更正為資產對營收約 **2.36**、資本支出 $1,069M 約占營收 **6.1%**。答案結論 Yes 對、資本支出對,但資產對營收算成 1.36(營收取 FY2024、資產取錯),仍判 P。

## 用量與耗時(訓練集與獨立題組分開)

| | 訓練集 | 獨立題組 |
|---|---|---|
| 整段執行時間 | 1,278 秒(21.3 分) | 1,062 秒(17.7 分) |
| 每題耗時 平均 / 中位 / 最慢(秒) | 31.7 / 28.8 / 99.1 | 27.6 / 25.9 / 65.7 |
| 模型呼叫 | 273(答案 150、拆題器 123) | 285(答案 150、拆題器 135) |
| token 合計 | 2,452,047 | 2,560,852 |
| 每題 token | 16,347 | 17,072 |

- 兩個集合合計 5,012,899 token(免費額度內)。
- 每題耗時是 4 個程序同時跑時的單題時間,不是單獨執行的延遲。
- 帳本沒有題號,切到訓練集與獨立題組靠兩個階段的時間窗(`run_windows.json`);兩階段依序執行、沒有重疊,冒煙測試的 2 題在時間窗之前,不計入。

## 檔案

| 檔案 | 內容 |
|---|---|
| `answers.json` | 300 題完整紀錄:題目、標準答案、模型答案、耗時、標籤、依據、說明 |
