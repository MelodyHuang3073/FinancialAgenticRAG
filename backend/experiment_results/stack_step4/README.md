# 疊加第 4 步:+ C5 系統檢索器(單檔 300 題)

疊加實驗的第 4 步(2026-11-08 修訂版規劃,見上一層的 [EXPERIMENT_PLAN.md](../EXPERIMENT_PLAN.md)),評分規則在其第 9 節。

## 這一步的設定

在第 3 步之上只換檢索器(C5),沒有加任何完整系統沒有的東西。

| 項目 | 內容 |
|---|---|
| 日期 | 2026-11-09 |
| 程式 | `backend/stack_runner/run_step.py --step 4`(本分支,「疊加實驗第 4 步程式」的 commit),4 個程序同時跑(兩個題組各切 2 份),先冒煙測試 2 題 |
| 模型 | gpt-5-mini;作答一次呼叫兩則訊息(系統訊息、使用者訊息),不設任何其他參數;拆題器另有自己的模型呼叫 |
| 規劃 | 與第 3 步相同(系統的規劃器:題型判斷、公司對齊、公式庫、趨勢題補前一年、`_plan_queries`) |
| 檢索 | 由系統的 orchestrator 自己跑第一輪:規劃出的每個查詢各搜一次(一般 top 5、敘述 top 15)、8 條加權、排除已取過的、跳過已有的(指標、年度)、每個查詢以自己的文字重算報表類型提示、去重、同公司限定、每個查詢保證 2 塊的配額、視窗 30;作答呼叫再從視窗 30 取 16 筆(系統的 `select_with_quota`)。PoT 與 Tri-Check 以「空結果、直接通過」取代,所以只跑第一輪、不重試 |
| 提示詞 | 與第 3 步完全相同(由系統的 `generate_answer` 組成,含兩行路由文字,沒有 Computed value 與 Verification summary);改變的只有放進去的證據 |
| 檢查 | 300 題齊全,0 次錯誤,沒有空答案,合併檢查通過,沒有 fallback 形式的答案;拆題器 234 次呼叫(與基準、第 3 步相同);離線測試:使用系統檢索器、一次嘗試無重試、提示詞框架與第 3 步相同(系統訊息、問題與模式與路由行、原則到檢查清單逐字相同)、每題從乾淨狀態開始 |
| 評分 | 依規劃第 9 節逐題讀完 300 題答案,對標準答案評分,非 C 的標籤記依據(決策表列號),通過 `grading_check.py`,與第 0 到 3 步及基準跨組比對,另做機械篩選(C 的答案要含標準答案的主要數字、非 C 的答案不得已含全部標準答案數字) |

視窗大小:視窗 30 的有 77 題,15 的 75 題,10 的 68 題(公式庫題每個變數各取 5 筆,所以 2 或 3 個變數的題視窗是 10 或 15),其餘 80 題介於其間。作答呼叫實際取到 16 筆的 155 題,少於 16 筆的 145 題(視窗本身不足 16)。

規劃的來源統計(`summary.json` 的 `decompose_source`)與第 3 步相同:只用公式 104 題、公式加主題查詢 8 題、模型拆題加問題原文 66 題、模型拆題加主題查詢加問題原文 55 題、只剩分類器的查詢 67 題。

## 跨組比對(規劃 9.6)

- 與第 3 步:標籤相同 275 題;與第 2 步:223 題;與第 1 步:220 題;與第 0 步:188 題;與基準:276 題。
- 基準非 C、這一步 C 的有 6 題(訓練集 61、135,獨立測試集 10、50、89、104);基準 C、這一步非 C 的有 16 題。
- 機械篩選:C 的 21 題標準答案主要數字不在答案裡,逐題重讀,都是寫法不同(1,577 對 1577.00、16.53% 對 16.5%、四捨五入到標準答案精度)、單位換算或文字型標準答案;非 C 的題沒有答案已含全部標準答案數字的。篩選抓到訓練集 62(波音訴訟),原判 C,重讀後答案只說「有多項訴訟」、沒有標準答案的獵鷹航空與衣索比亞航空事故,改判 P(第 15 列)。
- 與前幾步標籤不一致的題,把各組答案並排重讀後統一:
  - 訓練集 15(Adobe 自由現金流轉換):這一步答 165% 與 150%(用營運現金流,不是自由現金流),標準答案 156% 與 143%,方向(改善)對,判 P(第 6 列);第 3 步與基準答對 156% 與 143%,判 C。

## 用量

300 題:合計 4,848,619 token(作答 4,552,661、拆題器 295,958;輸入 4,296,836、輸出 551,783);呼叫 534 次(作答 300、拆題器 234)。作答提示詞字元中位數 54,777。每題耗時平均 16.2 秒、中位 14.5、最慢 47.8(含拆題器)。第 3 步是 5,416,912 token(提示詞較長:BM25 一律取 16 筆,系統檢索器的公式庫題只取 10 到 15 筆)。冒煙測試另外約 4 萬不計入;離線檢查時拆題器另外用了約 3 千 token,不計入。
