# 換模型實驗:完整系統只換作答與拆題的 LLM(OpenAI,單檔 300 題)

規劃見上一層的 [EXPERIMENT_PLAN.md](../EXPERIMENT_PLAN.md) 第 8 節,評分規則在第 9 節。完整系統(含 PoT、Tri-Check、重試)不動,只把所有 LLM 呼叫(作答、拆題器)從 gpt-5-mini 換成指定的 OpenAI 小模型,其餘設定與基準相同。系統本來就從環境變數 `OPENAI_MODEL` 選模型,所以這個分支沒有改 `app/`,只加執行工具(`backend/llm_runner/`)與離線測試。

**執行**

- 日期 2026-11-13;`backend/llm_runner/launch.ps1 -Model gpt-5-nano`,4 個程序同時跑(兩個題組各 2 份),23:11 開跑、00:00 前後(跨日) 結束,約 49 分鐘;程式 commit `63fc522`。先跑冒煙測試(每個程序 1 題,不計入結果),再跑 300 題。
