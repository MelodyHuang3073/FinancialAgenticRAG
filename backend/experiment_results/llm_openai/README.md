# 換模型實驗:完整系統只換作答與拆題的 LLM(OpenAI,單檔 300 題)

規劃見上一層的 [EXPERIMENT_PLAN.md](../EXPERIMENT_PLAN.md) 第 8 節,評分規則在第 9 節。完整系統(含 PoT、Tri-Check、重試)不動,只把所有 LLM 呼叫(作答、拆題器)從 gpt-5-mini 換成指定的 OpenAI 小模型,其餘設定與基準相同。系統本來就從環境變數 `OPENAI_MODEL` 選模型,所以這個分支沒有改 `app/`,只加執行工具(`backend/llm_runner/`)與離線測試。比較對象是基準(`../baseline/`)。

## 跨組比對(規劃 9.6)

- 標籤相同的題數:基準 261、疊加第 0 步 144、第 1 步 171、第 2 步 174、第 3 步 240、第 4 步 259、消融列 1 231、列 2a 253、列 2b 249、列 3 207、列 4 242、Gemini 3.1 244、Gemini 3.5 240。
- 基準非 C、這次 C 的 9 題(訓練集 109、獨立測試集 45、獨立測試集 87、獨立測試集 97、獨立測試集 106、獨立測試集 117、獨立測試集 129、獨立測試集 134、獨立測試集 146):逐題對照後都是這次的答案本身把標準答案要的內容寫對了。
- 基準 C、這次非 C 的 29 題:這些題非 C 的理由都在這次的答案本身(找不到、結論相反、口徑不同、缺項或取錯數字)。比對時發現訓練集 86 原先因為沒有寫營收成長率標為部分正確,但基準同樣沒有寫而判正確,依同一標準改判 C。
- 判斷依據的幾個決定:
  - 訓練集 6、145 與 32 的速動比率:訓練集 6 結論 No 與標準答案相同判 C;32 與 145 用流動資產減存貨計算,結論對但數值不同,判 P(第 6 列)。
  - 訓練集 56(Best Buy 表現最好的類別)與 109(MGM 表現最差地區):答案同時寫出兩種讀法,其中包含標準答案那一項,判 C。
  - 訓練集 62、64、66:缺少標準答案的主要內容(墜機訴訟、商用航空客戶、777X 增產),基準的答案有寫到,判 P。
  - 訓練集 78(CVS 訴訟):以鴉片類訴訟為主、沒寫藥價與 PBM 訴訟,和同樣內容判 C 的其他組一致,判 C;獨立測試集 31(American Express 辦公室位置)沒有寫出 200 Vesey Street,判 P(2026-11-25 跨組重審)。
  - 獨立測試集 106(Netflix EBITDA 利潤率)答 30.2%,只用現金流量表的折舊與攤銷,與標準答案相同,判 C。
  - 獨立測試集 54(Corning 光通訊占比)答財報自己印的 38%,判 C。
